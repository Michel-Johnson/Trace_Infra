# HTML 报告

HTML 应为自包含、可离线审阅的报告，不依赖运行中的 Trace Hunter 页面才能理解主要结论。

- 首屏展示状态、范围、样本、覆盖率和关键结论。
- 指标表保留单位、分母、unknown 和版本。
- 图表只用于确实改善分布、Cohort 或行为漏斗理解的场景。
- 典型案例默认折叠，展开后显示稳定证据引用与最小必要片段。
- 提供方法、限制、证据索引和结构化结果下载区。
- 使用语义化 HTML、键盘可达控件、可读对比度和打印样式。
- 不从外部 CDN 加载脚本、字体或追踪代码。

生成后检查桌面和窄屏布局，确认长 ID、正文片段、表格和代码不会溢出；报告中的链接必须指向固定 revision 或结果身份。
