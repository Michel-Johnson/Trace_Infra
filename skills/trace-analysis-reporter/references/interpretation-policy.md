# 解释规范

## 五类陈述

- **事实**：平台直接返回的 Trace/Span/Result 字段。
- **统计结果**：按 Spec 计算的指标，必须带分母和覆盖率。
- **解释**：对结果含义的有限说明，列出依据和替代解释。
- **假设**：Deep Dive 发现但尚未全量验证的问题。
- **建议**：基于已验证问题提出的行动与验证方式。

报告中显式区分这些类型。避免“明显、证明、导致、所有”等超出证据的措辞。

## Cohort

观察性 Cohort 使用“相关、差异、伴随”等措辞，并列出匹配条件与剩余混杂因素。只有受控实验满足随机/等价分配、环境隔离和独立 Verifier 时才讨论因果影响。

## Unknown 与 Partial

unknown 不是失败，partial 不是完整结果。报告比例时同时提供：明确分母、未知数量、排除数量和总候选数量。不同覆盖率结果不能只比较百分比。

## 证据引用

使用稳定对象身份和必要片段。正文需脱敏并限制长度；禁止复制完整 Trace 作为报告正文来替代分析。
